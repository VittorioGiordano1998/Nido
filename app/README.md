# Nido — app web

Client web di Nido (Vite + React + TypeScript + Tailwind CSS).

```sh
npm install
copy .env.example .env.local   # poi incolla URL e anon key del progetto Supabase
npm run dev
```

- `npm run dev` — dev server (Vite)
- `npm run build` — build di produzione (`tsc -b` + Vite)
- `npm run lint` — oxlint

Struttura del codice e regole: vedi il `README.md` nella cartella superiore e
`docs/agents/RULES.local.md`.
