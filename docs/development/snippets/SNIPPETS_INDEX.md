# Snippets Index

Reusable reference code — small, self-contained examples of a build-time processor, a
P/Invoke pattern, a CI step, or any other piece worth keeping verbatim. Snippets are code
to adapt, not libraries to depend on: they live in the repo so a pattern survives across
branches and machines, and they are covered by this index so nobody re-discovers them.

When adding a snippet, give it a descriptive name, keep it self-contained (a comment header
saying what it does and where it is applied), and add a row below.

| Snippet | What | Applies to |
|---|---|---|

Keep this index in sync when adding, replacing or removing a snippet.
